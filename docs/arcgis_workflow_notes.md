# ArcGIS workflow notes

This file summarizes the spatial-processing and map-production steps that were performed or checked in ArcGIS Desktop 10.8 for the manuscript:

"Climatic-baseline choice and temporal mismatch in species distribution models: effects on habitat suitability and transferability for Hemiscorpius acanthocercus (Scorpiones: Hemiscorpiidae) in Iran"

## Purpose

The Python scripts in this repository support the main computational analyses reported in the manuscript. However, the full workflow was not designed as a completely automated end-to-end pipeline.

Some final spatial processing, raster inspection, cartographic layout, visual checking, and map production steps were performed in ArcGIS Desktop 10.8.

## ArcGIS-related steps

ArcGIS Desktop 10.8 was used for selected steps, including:

- Visual inspection of raster alignment and spatial consistency
- Checking raster extent, mask, and NoData behavior
- Inspection of binary suitability maps
- Inspection of habitat-change and trajectory outputs
- Map layout and cartographic design
- Final figure preparation for manuscript presentation
- Visual checking of MESS and MoD spatial outputs
- Final map export and layout adjustment

## Repository scope

The scripts and documentation provided in this repository are intended to support transparency and reproducibility of the main analytical steps reported in the manuscript.

Large raster outputs, ArcGIS project files, intermediate GIS layers, raw occurrence records, field notes, and unpublished dissertation datasets are not redistributed in this repository.
