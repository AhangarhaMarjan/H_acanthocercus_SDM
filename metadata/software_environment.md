# Software environment

This file summarizes the main software and tools used in the analysis.

## Main software

- MaxEnt 3.4.4
- Python 3.x
- ArcGIS Desktop 10.8
- R

## Python use

Python scripts were used for supporting computational steps, including raster preparation, predictor screening, raster conversion, binary map generation, ensemble summaries, MESS/MoD summaries, habitat-dynamics calculations, and spatial agreement metrics.

## ArcGIS use

ArcGIS Desktop 10.8 was used for selected spatial processing, raster inspection, map preparation, cartographic layout, and final visual checking of spatial outputs.

## R use

R was used for selected bioclimatic-variable processing steps, including the derivation of bioclimatic predictors where applicable.

## Workflow note

The repository provides supporting scripts and workflow documentation. It is not intended to represent a fully automated end-to-end workflow, because selected spatial processing and cartographic steps were performed or checked in ArcGIS.
